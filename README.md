## Descripción del proyecto

Este proyecto desarrolla un análisis exploratorio de datos aplicado a las ventas y al comportamiento de los clientes de FerreMarket Perú.

El análisis permite explorar las ventas según producto, categoría, segmento, región y canal, identificando patrones relacionados con la facturación, los descuentos y el margen.

## Objetivo

Analizar el comportamiento de las ventas para identificar patrones y relaciones relevantes entre productos, categorías, segmentos, regiones y canales de venta.

El análisis busca generar información útil para comprender el comportamiento comercial y apoyar la toma de decisiones.

## Dataset

El dataset contiene información relacionada con las ventas de productos de ferretería y construcción.

Entre las principales variables analizadas se consideran:

- Producto
- Categoría
- Segmento
- Región
- Canal de venta
- Ventas
- Descuentos
- Margen
