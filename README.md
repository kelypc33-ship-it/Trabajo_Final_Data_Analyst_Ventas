# 📊 Análisis Exploratorio de Ventas y Comportamiento de Clientes

## 📌 Descripción del proyecto

Este proyecto presenta un análisis exploratorio de ventas y comportamiento de clientes utilizando Python y SQL.

El objetivo es analizar el desempeño comercial desde diferentes perspectivas, identificando patrones relacionados con ventas, productos, categorías, segmentos de clientes, regiones, canales, descuentos y rentabilidad.

El análisis busca transformar los datos en información útil para apoyar la toma de decisiones comerciales.

---

## 🎯 Objetivos

### Objetivo general

Analizar el comportamiento de las ventas y clientes para identificar patrones, oportunidades de crecimiento y posibles riesgos relacionados con la rentabilidad.

### Objetivos específicos

- Analizar la evolución de las ventas.
- Identificar las categorías con mayor facturación.
- Analizar el desempeño de los diferentes canales de venta.
- Comparar el comportamiento de los segmentos de clientes.
- Identificar las regiones con mayor participación en las ventas.
- Analizar la relación entre descuentos y margen.
- Comparar volumen de ventas y rentabilidad.
- Obtener insights mediante consultas SQL.

---

## ❓ Preguntas de negocio

El análisis busca responder las siguientes preguntas:

1. ¿Qué categorías generan mayores ventas?
2. ¿Cómo evolucionan las ventas a través del tiempo?
3. ¿Qué canales concentran la mayor facturación?
4. ¿Qué segmentos presentan mayor ticket promedio?
5. ¿Qué regiones presentan mayor desempeño comercial?
6. ¿Existe relación entre descuentos y margen?
7. ¿Las categorías que más venden son también las más rentables?
